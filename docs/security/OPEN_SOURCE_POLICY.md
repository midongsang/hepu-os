# 赫普OS 开源与厂商分发政策

**版本**：V1.0
**生效日期**：2026-08-21

---

## 1. 开源范围

### 1.1 开源组件（GPLv3）
- 赫普微内核核心（kernel/）
- H-HAL 硬件抽象层（kernel/hal/）
- 隐私沙盒核心（services/privacy-vault/）
- 窗口管理器与图形合成服务（services/graphics-server/）
- `.hug` 格式规范与工具链（hug-sdk/）
- 系统基础服务框架（services/）

### 1.2 闭源组件
- AI基座大模型权重文件
- 官方应用商店服务端代码
- 商业授权专属组件
- 厂商私有驱动（H-DPK中的二进制固件）

---

## 2. 开源协议

### 2.1 主协议：GPLv3
所有开源组件采用 **GNU General Public License v3.0**。

核心义务：
1. 修改后再分发，必须公开修改后的完整源代码
2. 衍生作品必须同样使用GPLv3协议
3. 利用反Tivoization条款：禁止厂商在硬件上封锁用户运行修改版内核的权利
4. 保留原始版权声明与许可证文本

### 2.2 附加补充条款（HEPU Additional Terms）
在GPLv3基础上，赫普OS项目附加以下条款：

**条款A：内核来源标注不可移除**
- 内核二进制镜像中内置的只读版权指纹（HEPU_FINGERPRINT）不得被删除、篡改或绕过
- 任何分发版本必须在用户可见界面保留内核来源声明

**条款B：商标使用限制**
- "赫普OS"、"HEPU OS"、"HEPU Hyper Evolve OS"名称及官方LOGO为项目商标
- 未经官方审核授权，第三方衍生版本不得使用上述商标
- 第三方衍生版本必须使用不同名称，并在显著位置说明"基于赫普OS开源代码"

**条款C：安全沙盒完整性**
- 不得移除或绕过隐私沙盒、权限管控机制
- 不得在系统中植入用户不可见的数据收集模块

---

## 3. 厂商分发规则

### 3.1 适用对象
手机硬件厂商、OEM厂商、任何将赫普OS用于商业设备销售的主体。

### 3.2 强制内核来源标注
厂商分发的任何版本（预装、OTA、刷机包）必须在以下三处标注：

**位置1：关于本机页面**
```
本设备内核基于 HEPU Hyper Evolve OS 赫普OS开源微内核
开源仓库：https://github.com/hepu-os/hepu-os
内核版本：<版本号>
```

**位置2：刷机包下载页面 / 说明文档**
- 明确标注内核来源与开源仓库地址
- 提供内核源代码下载链接

**位置3：开机版权提示**
- 开机动画结束后或设置入口中保留内核版权声明

### 3.3 技术兜底：内核只读版权指纹
- 内核二进制镜像内置不可篡改的版权元数据
- 系统启动时自检指纹完整性
- 指纹被篡改时，关于本机页面强制显示警示
- 指纹可被第三方审计工具提取，用于合规取证

### 3.4 厂商允许的定制
- 上层UI、主题、壁纸
- 自带系统应用（需遵守沙盒规范）
- 自有云服务、应用商店
- 功耗调度策略
- 设备专属H-DPK驱动适配包

### 3.5 厂商禁止行为
1. 删除、篡改内核来源声明与版权指纹
2. 修改内核后不公开源代码
3. 未经授权使用"赫普OS"商标进行商业宣传
4. 移除隐私沙盒或植入不可见数据收集
5. 封锁用户刷入修改版内核的权利（违反GPLv3反Tivoization）

## 4. 商业授权流程

### 4.1 何时需要商业授权
- 将赫普OS预装在商业售卖的硬件设备上
- 使用"赫普OS"官方商标进行市场宣传
- 需要官方技术支持与兼容性认证

### 4.2 授权条件
1. 签署商业授权协议
2. 提交内核修改部分的源代码供合规审查
3. 确认三处内核来源标注完整
4. 通过官方兼容性测试（设备三级分级认证）
5. 承诺不移除隐私沙盒与安全机制

### 4.3 社区个人使用
- 个人爱好者编译、刷入、修改无需商业授权
- 个人衍生版本不得用于商业设备销售
- 个人衍生版本必须改名，不得使用官方商标

## 5. 衍生版本命名规范

第三方衍生版本命名格式：
```
<自定义名称> (based on HEPU OS)
```

示例：
- ✅ "PureMobile OS (based on HEPU OS)"
- ❌ "赫普OS 魔改版"
- ❌ "HEPU OS Pro"

必须在关于页面注明：
```
本系统为第三方衍生版本，基于赫普OS开源微内核修改
非官方版本，官方不承担质量与安全责任
```

---

## 6. 合规审计与违规处理

### 6.1 审计方式
1. 官方定期抽查市场上的商业设备
2. 社区举报机制
3. 内核版权指纹远程校验工具
4. CI流水线代码指纹扫描

### 6.2 违规处理
1. 首次违规：书面通知，限期整改
2. 逾期未改：公开通报，撤销商标授权
3. 严重违规：依据GPLv3与附加条款启动法律程序
4. 违规厂商列入不合作名单

---

## 7. 漏洞响应

### 7.1 漏洞披露
- 安全漏洞请发送至 security@hepu-os.org
- 漏洞报告加密（PGP公钥见官网）
- 项目承诺90天内修复并公开

### 7.2 漏洞赏金
- 关键漏洞（内核远程代码执行）：高额赏金
- 高危漏洞（沙盒逃逸、权限提升）：中等赏金
- 中低危漏洞：荣誉名单 + 小额奖励

### 7.3 修复流程
1. 内部确认与修复
2. 同步给商业授权厂商
3. 公开源码补丁
4. 发布安全公告
