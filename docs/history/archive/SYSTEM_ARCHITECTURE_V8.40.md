## 一、系统概述

赫普OS（Hepu OS）是一个自研的微内核架构操作系统，采用C语言核心内核+汇编最底层+Rust用户态渐进引入的技术路线。系统支持x86（32位）架构，具备完整的内核基础功能、驱动支持、网络协议栈、文件系统、图形子系统和安全机制。

### 设计理念
- **系统归人，数据归己，自由可控，极致纯净**
- 微内核架构：核心功能在内核，服务在用户态
- 安全优先：内存隔离、用户指针校验、加密存储
- 渐进式完善：先最小可用，再逐步完善

## 三、内核子系统

### 3.1 进程管理
- **进程模型**：128个进程上限，每个进程独立地址空间
- **调度器**：优先级调度，支持时间片轮转
- **进程状态**：运行/就绪/阻塞/僵尸
- **系统调用**：fork/clone/execve/waitpid/exit/getpid
- **信号**：支持kill/signal，信号处理函数
- **进程间通信（IPC）**：
  - 信号量（semaphore）
  - 共享内存
  - 消息队列（FIFO）
  - 互斥锁（mutex）
  - IPC权限控制

### 3.2 内存管理
- **物理内存管理**：位图分配器，支持4GB物理内存
- **虚拟内存**：二级页表（x86），支持PAE扩展
- **内核堆**：slab分配器，多级缓存
- **用户态堆**：sys_brk系统调用，独立用户堆
- **内存压缩**：zram支持（1MB压缩缓存）
- **内存隔离**：用户态与内核态页表隔离
- **统一内存架构**：内存/显存/存储统一管理

### 3.3 文件系统
- **VFS虚拟文件系统**：统一文件操作接口
- **ext2文件系统**：完整实现，支持100GB根分区
- **文件系统功能**：
  - 文件创建/删除/读写
  - 目录操作
  - 软链接/硬链接
  - 文件权限（chmod/chown）
  - 挂载点（32个）
- **文件系统检查**：fsck工具，支持修复模式
- **加密文件系统**：fscrypt，AES-256-CBC真实加密
- **文件描述符**：128个/进程

### 3.4 网络协议栈
- **物理层**：RTL8139/e1000双网卡驱动
- **链路层**：ARP协议
- **网络层**：IPv4协议，路由，广播
- **传输层**：TCP/UDP协议
- **应用层**：
  - DHCP客户端（完整状态机）
  - DNS域名解析
  - HTTP/1.0客户端和服务器
  - FTP客户端
  - SMTP/POP3邮件客户端
  - WebSocket
  - TLS 1.2加密传输
- **Socket API**：BSD Socket兼容接口

### 3.5 图形子系统
- **可插拔图形架构**：统一API+多后端
- **显示后端**：
  - GOP（UEFI Graphics Output Protocol）
  - VGA文本模式
  - VBE（VESA BIOS Extensions）
  - virtio-gpu（虚拟化GPU）
- **字体系统**：
  - TrueType解析器（完整光栅化+复合字形+Hinting）
  - 字体管理器（多字体+回退机制+缓存）
  - CJK中文字体支持（GB2312全汉字集，6896字符）
  - 抗锯齿渲染
- **窗口系统**：窗口创建/移动/缩放/关闭/Z轴
- **UI组件**：按钮/输入框/列表/菜单/对话框
- **桌面环境**：状态栏/图标/Dock/系统设置

### 3.6 安全机制
- **内存隔离**：用户态与内核态页表隔离
- **用户指针校验**：所有系统调用copy_from/to_user
- **系统调用过滤**：沙箱机制
- **加密存储**：AES-256-CBC文件加密
- **安全启动**：UEFI Secure Boot签名
- **密码学库**：
  - AES（ECB/CBC/GCM）
  - HMAC-SHA256
  - SHA-256
  - RSA（已修复模运算错误）
  - X.509证书解析+验签
  - TLS 1.2完整实现
- **CSPRNG**：ChaCha20，多源熵收集

## 十、开发规范

### 代码规范
- C语言：C11标准，4空格缩进
- 汇编：AT&T语法
- Rust：2021 edition
- 注释：中文注释，函数头说明

### 提交规范
- 每次交付四件套：源码+ISO+IMG+数据盘
- 文档版本与镜像版本对应
- 错误历史完整记录
- 规范化修复，避免错删误判

### 安全规范
- 所有系统调用必须校验用户指针
- 内存分配必须检查返回值
- 数组访问必须边界检查
- 加密算法必须使用标准实现
