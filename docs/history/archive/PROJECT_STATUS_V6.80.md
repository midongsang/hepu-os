## 四、近期版本更新

### V6.76 - 系统资源扩展
- 物理内存 256MB → 4GB
- IDE存储 128GB → 2TB (LBA48)
- VVRAM显存 16MB → 64MB (6级动态降级)
- 进程 64 → 128，FD 64 → 128
- 内核堆3级 → 5级自适应

### V6.77 - PAE数据结构与存储显存
- PAE物理地址扩展数据结构 (36位/64GB)
- 存储-backed显存驱动 (SBVR)
- Swap磁盘分区支持 (2048槽/8MB)

### V6.78 - 存储显存集成与swap自动检测
- VVRAM集成存储显存 (VVRAM_TECH_STORAGE)
- Swap磁盘分区自动检测 (MBR扫描)
- BUG-26修复 (IDE参数顺序+返回值检查)

### V6.79 - PAE启用框架
- PAE CPU检测集成到paging_init
- PAE分页管理模块 (paging_pae.c)
- 11个Rust用户态程序编译并放入数据盘

### V6.80 - 图形系统完善
- 图形系统自测 (gfx_selftest.c，18/21通过)
- 弹性桌面渲染器 (desktop_render.c)
- 弹性桌面主循环 (鼠标拖拽/ESC退出)
- edesktop Shell命令
