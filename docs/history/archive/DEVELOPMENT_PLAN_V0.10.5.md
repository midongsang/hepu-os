# HepuOS 开发规划 V0.10.5

## 现状评估
- 模拟器内可启动、显示桌面、36个应用、610个测试用例全部通过
- 真机启动失败（光标闪一下回Windows）
- 网络协议栈模拟实现，不真实收发包
- GPU只有virtio-gpu 2D，无Mesa/OpenGL
- 无POSIX完整兼容层，不能跑第三方软件
- 所有进程uid=0，无真实多用户隔离

## P0 阻塞项（必须先解决）

### P0-1 真机UEFI启动兼容性
**问题**：真机启动光标闪一下就回Windows
**可能原因**：
1. HepuBoot UEFI应用在某些真机固件上加载失败
2. 内核加载地址（0x100000）与固件保留区冲突
3. GOP帧缓冲地址（0x80000000）在真机上不可用
4. 内核入口跳转时寄存器状态不正确
5. Secure Boot未正确处理

**开发任务**：
- [ ] 添加UEFI启动调试输出（串口/屏幕）
- [ ] 实现多帧缓冲地址探测（不硬编码0x80000000）
- [ ] 内核加载地址动态分配（不硬编码0x100000）
- [ ] 添加启动失败回退机制（显示错误码）
- [ ] 验证常见真机UEFI固件兼容性
- [ ] 确保IMG镜像GPT分区表符合UEFI规范

**验证标准**：在至少1台真机上成功启动到桌面

### P0-2 真实网络协议栈
**问题**：tcp.c/http.c/websocket.c都是模拟实现
**开发任务**：
- [ ] RTL8139网卡驱动真实收发包
- [ ] e1000网卡驱动真实收发包
- [ ] ARP协议真实实现
- [ ] IP协议真实实现（分片/重组）
- [ ] ICMP协议（ping）
- [ ] UDP协议真实实现
- [ ] TCP协议真实实现（三次握手/滑动窗口/重传）
- [ ] DNS客户端真实实现

**验证标准**：QEMU内ping通网关，TCP连接成功
