## 3. 开发规范速查（硬性约束，详见 DESIGN.md 头部与 E-121）

1. **兼容层用户态化**：EXE/ELF/macOS 加载翻译禁止入内核
2. **统一沙盒**：所有应用类型同一沙盒，权限只降不升
3. **预期管理**：兼容等级标注，禁止"完美运行"绝对化表述
4. **stage2 ≤ 2048B**：超限必须精简
5. **引导兼容最高准则**：任何新老 x86 设备只要能引导就必须能启动赫普OS
6. **禁止事项**：中断内复杂计算、持锁睡眠、内核/用户态混用指针、释放后不置空、全局大锁
7. **发布验证**：QEMU SeaBIOS 全链路 / LBA 成功 / CHS 兜底 / 错误显示完整
