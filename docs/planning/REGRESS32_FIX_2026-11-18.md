# 32 位既有链接失败修复记录（2026-11-18）

> 范围：仅修复 `bash tools/regress32.sh` 基线即失败的 32 位内核链接问题。
> 不改 `docs/planning/ROADMAP.md` 正文；不碰 `kernel/arch/aarch64/m1/`、能力审计/diag、`docs/architecture`、`docs/status`、VFS。

## 1. 现象与根因

**基线（HEAD `efbd497`，epoll 改动已 stash）32 位链接即失败**，与本次 epoll/eventfd 改动无关：

```
ld: build_v250/arch/x86_64/hpdesk.o: undefined reference to `auth64_user_name'
ld: build_v250/arch/x86_64/hpdesk.o: undefined reference to `auth64_current_role'
ld: build_v250/arch/x86_64/hpdesk.o: undefined reference to `rtc64_get_timestamp'
make: *** [Makefile:550: build_v250/kernel.elf] Error 1
```

**根因链**：

1. 根 `Makefile` 的 `HP_DESK_DEPS`（约 :67-72）把 64 位共用桌面层 `hpdesk.c` 等放行进 32 位构建；`C_SRCS`（:74）先 `filter-out arch/x86_64/%`，再追加 `HP_DESK_DEPS`。
2. `hpdesk.c` 引用账户子系统 `auth64_*` 与时钟 `rtc64_*`，其定义方在被 `filter-out` 排除的 `kernel/arch/x86_64/`（`auth64.c`、`rtc64.c`），32 位树无对应定义，链接报未定义符号。
3. 引入提交：`3f0edb1`（2026-11-18，feat(desktop) 屏保设置 + 设置页 Accounts 账户管理）。

**符号全集（从 `hpdesk.c` 枚举，其余共享源 `hs_ui.c/hsqml.c/l10n64.c/png64.c` 均无引用）**：

| 类别 | 符号 | 32 位既有状态 |
|---|---|---|
| RTC 字段 | `rtc64_get_hours/minutes/seconds/day/month/year/weekday` | 已由 `kernel/arch/x86/gfx64_compat_ext.c` 接 32 位 `rtc_get_time` 实现 |
| RTC 时间戳 | `rtc64_get_timestamp` | **缺失**（本次补） |
| 账户 | `auth64_user_name` / `auth64_current_role` / `auth64_is_configured` / `auth64_verify_password` / `auth64_create_account` | **缺失**（本次补兼容桩） |

## 2. 方案决策（真实现优先，接不上才桩）

### 2.1 RTC：复用既有 32 位 CMOS 兼容层（真实时间派生，非常量桩）

`rtc64.c` 本身是纯 CMOS 端口访问（`inb/outb`），可 `-m32` 编译通过；但 `gfx64_compat_ext.c` 已用 32 位 `rtc_get_time` 提供了全部字段 getter，再纳入 `rtc64.c` 会造成同名符号链接冲突。故**不纳入 `rtc64.c`**，改为在既有兼容层补 `rtc64_get_timestamp()`：由 32 位 `rtc_get_time()` 读 CMOS 年月日时分秒，按与 64 位 `rtc64.c:184-219` 相同口径折算 epoch（2000-01-01 起算，加 `946684800`；闰年 `(y%4==0&&y%100!=0)||y%400==0`）。读失败返回 0。

### 2.2 账户：最小 32 位兼容桩（非真实账户）

`auth64.c` 虽能 `-m32` 编译过，但链接依赖 64 位 FS 后端 `ext2_64_read_file/write_file`（定义方 `arch/x86_64/ext2_64.c`，32 位树无对应）；整体纳入会连带拖入 64 位 ext2 层，超出本次修复边界。故在 `kernel/arch/x86/` 下新建同签名最小兼容实现：

- `auth64_user_name()` → 空串；
- `auth64_current_role()` → `ROLE_NONE(0)`；
- `auth64_is_configured()` → 0；
- `auth64_verify_password(pass)` → 0（恒失败）；
- `auth64_create_account(name, pass, role, admin_pass)` → -1（32 位兼容层不持久化账户）。

**未改 `hpdesk.c` 任何 UI/业务逻辑**；桩只提供链接所需的安全兜底语义。

### 2.3 构建接入

`kernel/arch/x86/*.c` 由 `C_SRCS` 的 `find kernel -name "*.c"` 自动收集（不在 `filter-out` 内），新桩文件自动编入，**根 `Makefile` 无需改动**。

## 3. 真实现 / 桩 划分

| 部分 | 性质 | 说明 |
|---|---|---|
| `rtc64_get_timestamp` | **真实时间派生** | 读 32 位 CMOS `rtc_get_time` 折算 epoch；非写死常量 |
| `auth64_*` 五个符号 | **兼容桩** | 无账户持久化、无密码校验、角色恒 NONE；仅为链接兜底 |
