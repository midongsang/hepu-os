# HepuOS 系统验证计划 V0.10.1

> 文档版本：V1.0  
> 创建日期：2026-10-07  
> 适用版本：HepuOS 0.10.1  
> 维护者：HepuOS 开发团队

---

## 一、验证目标

### 1.1 总体目标
建立系统化、可重复、自动化的验证体系，确保HepuOS在每次迭代后：
- 核心功能不回归
- 新功能符合设计预期
- 性能指标满足基线
- 安全漏洞已修复
- 真机兼容性达标

### 1.2 验证范围
| 层级 | 范围 | 验证方式 |
|------|------|----------|
| 内核层 | 调度、内存、中断、系统调用 | 单元测试+集成测试 |
| 驱动层 | 磁盘、网卡、显卡、USB、声卡 | 硬件在环测试 |
| 文件系统 | ext2/FAT32/VFS | 挂载/读写/异常测试 |
| 网络层 | TCP/IP、Socket、TLS | 端到端测试 |
| 图形层 | VBE/VGA/GOP、字体、窗口 | 渲染对比测试 |
| 应用层 | 36个桌面应用 | UI交互测试 |
| 引导层 | HepuBoot UEFI/BIOS | 启动测试 |
| 安全层 | 内存隔离、系统调用校验 | 渗透测试 |

## 二、验证阶段划分

### 阶段1：提交前验证（Pre-commit）
**触发时机**：每次代码提交前  
**执行方式**：开发者本地执行  
**耗时目标**：< 5分钟

| 编号 | 验证项 | 工具/方法 | 通过标准 |
|------|--------|-----------|----------|
| P1-1 | 编译通过 | `make` | 0 error, 0 warning |
| P1-2 | 静态检查 | `gcc -Wall -Wextra` | 无新增warning |
| P1-3 | 内核单元测试 | `kunit` | 全部通过 |
| P1-4 | 代码规范检查 | 自定义脚本 | 符合编码规范 |
| P1-5 | 版本号一致性 | 版本检查脚本 | 内核/文档/镜像版本一致 |

### 阶段2：每日构建验证（Daily Build）
**触发时机**：每日自动构建  
**执行方式**：CI自动执行  
**耗时目标**：< 30分钟

| 编号 | 验证项 | 工具/方法 | 通过标准 |
|------|--------|-----------|----------|
| D1-1 | 完整编译 | `make clean && make` | 编译成功 |
| D1-2 | 四件套构建 | 构建脚本 | 源码/ISO/IMG/数据盘生成 |
| D1-3 | QEMU启动测试 | QEMU+OVMF | 5秒内进入桌面 |
| D1-4 | 内核自测 | gfx_selftest/fs_selftest | 全部通过 |
| D1-5 | 基准测试 | kbench | 性能不下降>5% |
| D1-6 | 镜像大小检查 | 脚本 | 内核<5MB, ISO<150MB |

### 阶段3：迭代验证（Sprint Verification）
**触发时机**：每个版本迭代结束  
**执行方式**：测试团队执行  
**耗时目标**：< 4小时

| 编号 | 验证项 | 详细内容 |
|------|--------|----------|
| S1 | 内核功能验证 | 调度/内存/IPC/系统调用全量测试 |
| S2 | 驱动验证 | 磁盘/网卡/显卡/USB/声卡功能测试 |
| S3 | 文件系统验证 | ext2/FAT32读写/异常/恢复测试 |
| S4 | 网络验证 | TCP/UDP/HTTP/TLS端到端测试 |
| S5 | 图形验证 | 分辨率/字体/窗口/应用UI测试 |
| S6 | 应用验证 | 36个桌面应用功能测试 |
| S7 | 安全验证 | 漏洞回归+新增渗透测试 |
| S8 | 性能验证 | 启动时间/内存占用/响应延迟 |

### 阶段4：发布验证（Release Verification）
**触发时机**：版本发布前  
**执行方式**：全量回归+真机测试  
**耗时目标**：< 24小时

| 编号 | 验证项 | 详细内容 |
|------|--------|----------|
| R1 | 全量回归测试 | 阶段1-3全部测试项 |
| R2 | 真机启动测试 | 至少3种不同硬件配置 |
| R3 | Secure Boot测试 | 签名验证+密钥管理 |
| R4 | 长时间运行测试 | 72小时连续运行无崩溃 |
| R5 | 兼容性测试 | 不同内存/显卡/CPU配置 |
| R6 | 文档验证 | 文档与功能一致性检查 |
| R7 | 版本一致性 | 源码/镜像/文档版本号统一 |
